# E-Fit

Kişisel kullanım için hazırlanmış, telefona yüklenebilen (PWA) antrenman koçu.

- Haftada 3 gün, 12 haftalık tüm vücut programı; her antrenmandan sonra ağırlıkları otomatik planlar
- Hedef / gerçekleşen set takibi, aylık takvim, vücut ölçüleri ve ilerleme grafikleri
- Tüm veriler yalnızca cihazda (tarayıcı depolaması) tutulur; internet olmadan çalışır

Hareket görselleri: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense).
